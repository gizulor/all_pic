h1. Overview

*Overview*

* In the @Write@ panel, find and add images to the @Article Image@ field or any specified @custom field@.
* The default @Images@ panel opens in a *SideView*, providing upload, edit and search capabilities.
* *SideView* is optimised to show more thumbs without scrolling.
* Drag thumbs from *SideView* straight into a field, or onto the *Body* or *Excerpt* to insert a gallery @shortcode@ at that spot.
* Preview, reorder and edit the images of a @shortcode@ in the body field.
* Thumbnails can be rearranged and moved to other groups via dragging.
* Thumbnails adjust their size according to the number of siblings.

h2. Requirements

* Textpattern 4.8.0+
* A modern web browser
* Image thumbnails need to be available in your @images/@ directory

h2. Installation

If using Textpattern 4.9+, upload the *all_pic.zip* file using the installer in the @Plugins@ tab.

For all versions of Textpattern, upload an unzipped version to your plugins folder using ftp, and then @Load from drive@ in the @Plugins@ tab.

Once installed, activate the plugin, then visit the @Write@ tab. You'll find an @Add images@ link in the @Article Image@ panel.

h2. Configuration

Visit @allPic@ in the @Preferences@ tab.

; *Specified fields*
: Enter a comma-separated list of the *CSS IDs* of your input fields. By default, allPic specifies the @#article-image@ field only, but you can add others separated by commas eg. @#article-image, #custom-1, #custom-3@ etc.
: Only @#article-image@ and @#custom-n@ fields are supported; anything else is ignored.
; *Gallery shortcode*
: Enter your shortcode, but leave out the closer @/>@ tag eg. @<txp::gallery @ or @<txp::my_shortcode foo="bar" @.
: Any shortcode that specifies an image is suitable; leave out the image @id@ attribute as this is determined by the plugin.
; *Single image shortcode* (optional)
: Used instead when a single image is dropped, eg. @<txp::figure @. Leave it blank to use the gallery shortcode for single images too.

h2. General Usage

Click on the @Add images@ link; the @Images@ panel will display in *SideView*.

* Drag a thumbnail from the list to a specified field in your article, or
* Select the checkboxes of one or more images and drag any one of them: all the selected images come along, or
* Select the checkboxes of one or more images, then click on @Article image@ (or any other custom field) in the *SideView* header

An empty field shows a *Drag images here* box to drop onto.

The image thumbs will display below their respective field:

* Change the order of the thumbs by dragging them, or drag them to another field
* Click on a thumb's delete button to remove it from the list
* Click on a thumb's edit button, and an @Image edit@ panel will open in *SideView*. Once you save your changes (or replace the image or its thumbnail), the thumb updates in your article.
* An image id with no image behind it (eg. a deleted image) shows as a dashed @123?@ tile, so it isn't silently dropped. Remove it with its delete button.

h2. Shortcodes

Drag a thumb (or a selection of thumbs) from *SideView* onto the *Body* or *Excerpt* field, and the shortcode is inserted where you drop it, eg. @<txp::gallery id="1,2,3" />@. A single image uses the *Single image shortcode* if you've set one.

If you have not created a form with the same name as your shortcode, Textpattern will ignore it.

Create a form called @gallery.txp@ in @Presentation: Forms@:

bc.. <txp:images id='<txp:yield name="id" />' break="" wraptag="div" class="gallery">
  <figure>
    <img src="<txp:image_url />" alt="<txp:image_info type="name" />" />
    <txp:evaluate><txp:image_info escape="textile" wraptag="figcaption" /></txp:evaluate>
  </figure>
</txp:images>

p. Paste the shortcode into an article body field, *Save* and click *View*. Without any css to control the layout, your images will display one above the other.

To add layout, include the following to your site's css:

bc.. .gallery {
    display: grid;
    gap: 1rem;
    grid-template-columns: repeat(auto-fit, minmax(300px,1fr));
    /* assumes max-width is not already specified in your css */
    img { max-width: 100%;}
  }


p. The images will distribute in rows depending on the width of the gallery. The same shortcode can be used in your form template:

bc.. <txp:if_article_image>
  <txp::gallery id='<txp:custom_field name="article-image" />' />
</txp:if_article_image>

h2. Shortcode previews in the body field

Once you have one or more shortcodes in amongst your text copy, click within the shortcode, and a *Preview* button will display, allowing you to see (and re-order) your thumbs. Add more by dragging them in from *SideView*, or remove them with their delete buttons. Click *Confirm* and your shortcode is updated; any other attributes in the tag are kept.
